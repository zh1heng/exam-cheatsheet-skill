# 条目与验证

按具体课程和用户需求调整结构；不必把全部审查字段塞进打印小抄。

## 一个可用条目

| 字段 | 应包含什么 |
|---|---|
| 稳定编号与入口 | 题目原词、常见问法、必要同义词；入口在实际成品中可见 |
| 题型与主分区 | 从题型先定位到页/栏；组合题提供明确跨区条目跳转 |
| 判断依据 | 看见哪些条件选这个方法；哪些相似条件应选别的方法 |
| 操作步骤 | 先检查、计算或标记什么，下一步怎么做，何时停止 |
| 必须交付 | 例如边集合、树图和总权重；或者结论、证据和理由 |
| 答案模板 | 简短且条件正确的句子或骨架；说明填什么，不能一概照抄什么 |
| 可组合与迁移 | 与其他模板如何衔接，适用边界及必要条件，不能只保存某道原题答案 |
| 易错区别 | 最容易混淆的目标、前提、符号、方向、表示形式 |

“找问题、解释理由、提出改进”只是任务名称。真正的步骤要说明如何识别问题、通过什么机制造成后果，以及什么改变能针对该问题。

语言是配置项。按识题、理解和作答分工，而不是整段重复翻译；详见 [language-design.md](language-design.md)。中文理解、英文作答适合某些学生，但不是所有考试的通用要求。颜色也按用途配置，例如入口、解释、答案模板分别使用一致样式；不能只靠颜色传递信息。

## 题目到小抄的审查表

| 题源定位 | 原词/情境线索 | 成品版本与条目 | 方法/条件 | 要改哪些参数 | 所需输出是否支持 | 缺口/状态 |
|---|---|---|---|---|---|---|

来源定位记录实际文件、物理页码或章节，以及题号。若印刷页码不同则区分。没有原题时写待核验；改编、自拟和教师原题分别标注。

默认只为选中的代表题及必要变式记录完整答案、评分要点与支持证据：预先固定权重和关键项，按模板组合的并集计算支持率。实测题≥90%且关键项受支持、完整答案正确才满足支持门槛；另查实际定位。未选原题只保留分类及代表映射，不生成逐题答案或详细评分账本。代表集与增量复测见 [peer-review-and-layout.md](peer-review-and-layout.md)；用户明确要求全量逐题验收时才使用 [acceptance-harness.md](acceptance-harness.md) 的严格账本。

分类应识别下列有意义的差异，必要时拆为子类或补代表；仅数值和情境名称不同的同类题无需重复作答：

- 概念被直接点名的问法，以及只给情境线索的问法。
- 同一方法中会改变答案的条件变化。
- 相似关键词但目标不同的题。
- 不同输出形式，如解释、手算、画图、代码或证明。

不要为每个无关情境名词建立索引，也不要把所有同义词挤进标题。保留最能引导判断的词，并在伴随索引中容纳长别名。

## 分开报告验证结果

| 维度 | 合适的证据 | 不能据此推出什么 |
|---|---|---|
| 内容覆盖 | 与当前范围逐项核对，记录缺口 | 不能推出今年考哪些题 |
| 可定位性 | 从原题措辞走到实际成品入口 | 助手找到不等于学生能快速找到 |
| 解题支持 | 额外独立 agent 对代表题和必要变式实际作答，记录条件、步骤、输出及小抄外知识 | 代表题通过不等于所有成员逐题通过，也不能保证未提供的题目可用 |
| 版面质量 | 渲染最终文件，逐页检查 | 不能替代实际打印体验 |
| 打印体验 | 实际尺寸试印并由使用者阅读 | 不能替代独立做题 |
| 独立掌握 | 学生独立提交答案并完成核验 | 引导示范、看懂或收到文件不算 |

避免默认选择极小字号；本项目最小有效印刷字号为 **5pt**，考试要求更大时从其规定。字号、页数、栏数、方向、纸张与语言都应服从当前考试要求和使用者的可读性。达到页数限制而未裁切，只能说明相应排版检查通过。独立解题、反馈循环与详细版面门槛见 [peer-review-and-layout.md](peer-review-and-layout.md)；资料优先级与单/双面限制见 [source-priority.md](source-priority.md)。

## 更新已有小抄

先识别用户手里的具体版本。保护旧版，按请求修改；保留稳定编号，若必须变化则给出旧→新映射。修复后复查周围内容、页数、引用入口和最终渲染。

打印版正文保持紧凑。完整来源、长推导、练习状态和验收记录放在伴随文档中，除非用户明确要求出现在小抄上。
