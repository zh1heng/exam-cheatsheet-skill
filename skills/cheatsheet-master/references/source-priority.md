# 课程资料优先级与考试限制

先判断资料在回答什么问题，再比较权威性、适用学期、发布日期与是否有明确更正。不要把所有资料混成一个按文件日期排序的列表。

## 来源优先级

| 要确定的事项 | 优先依据 | 补充与冲突处理 |
|---|---|---|
| 可带什么、纸张与面数、打印/手写限制 | 本次考试的正式通知、考试说明及有权限教师的正式澄清 | 旧卷封面、旧年规定、个人总结不能覆盖当前规定；正式规定与口头说法冲突时保留冲突并核实 |
| 本学期可考范围与排除项 | 本学期明确的课程通知，以及核实过的任课教师直接说明 | 专门的范围更正比仅仅在讲义中出现更有针对性；“没讲到”“没在旧卷出现”不能推导为不考 |
| 老师强调什么、怎样作答、课件有什么更正 | 老师录音/转录中的直接说明，连同对应课件、官方解答或书面更正 | 主动检索并提取，不能因为信息没有出现在幻灯片就漏掉；明确纠错可修正旧课件，但转录误识别必须核实 |
| 定义、算法、符号、条件和代码约定 | 本学期讲义、官方练习/解答，以及已核实的教师纠错 | 发现相互矛盾或疑似答案错误时分析并记录，不因“官方”标签忽略明显问题 |
| 某道题究竟要求什么 | 该题原始题面及其正式更正；官方评分标准若有 | 题目的条件、输出和给定量表优先于通用模板；建议得分点不能冒充官方逐步分值 |
| 问题风格、常见变式和旧年频次 | 已核实的正式旧卷，其次为指定 mock、课堂/作业练习 | 频次统计去重并区分正式卷与模拟题；不推算今年概率；不能用旧卷替代本学期覆盖 |
| 辅助解释与补缺 | 教材、个人笔记、旧小抄、外部资料、AI 生成内容 | 明确来源属性，回到课程约定核对，不能让二手总结覆盖一手证据 |

## 录音与转录怎么用

优先寻找考前答疑、复习课，以及含 `exam / assessable / not examinable / correction / show your working / marks` 等表述的位置；不要只做词搜索而忽略上下文。

为相关声明记录：

| 课程/学期 | 录音日期与说话者 | 文件与时间戳/转录行号 | 短原话与上下文 | 声明类型 | 影响条目 | 核验状态 |
|---|---|---|---|---|---|---|

声明类型分为：**明确范围、明确排除、纠错、作答要求、教学强调、一般建议**。强调或反复讲解不等于承诺必考。保留否定词、限定条件和老师是在读学生问题还是给出自己的回答等上下文。

转录是录音的派生记录，不自动等于逐字可靠原文。涉及排除、否定、公式、数字或疑似识别错误时，回听时间戳附近音频，或用可靠书面澄清交叉核实。没有音频或核实不了就标“待核验”，不要悄悄删掉可能在范围内的内容。时间戳缺失时用转录行号，不编造时间。

## 先锁定版面约束

记录来源与具体值：纸张尺寸、允许纸张数、每张可用面数、打印/手写、字体下限、颜色限制、是否允许附加材料，以及拟用打印缩放。

- `one A4 sheet` 只确定纸张数；单双面仍需看完整规定。
- 明确 `one side / single-sided`：主小抄必须为 **1 页 A4，单面**，不能把溢出内容放背面或另加一页带入考试。
- 明确 `one sheet, both sides`：最多 **2 页 A4**；两页 PDF 与两张纸不是同一件事，需正确设置双面打印。
- 图解、来源表和验收报告可以单独保留作复习材料，但除非规则允许，不能称为可额外携带的考试材料。
- 不明确的规则先查已有本学期证据；仍缺失时明确工作假设或询问关键限制，不能把假设写成已确认许可。

将这些约束作为后续验收条件。排版困难时压缩重复、调整结构或协商内容取舍，不自动改变允许面数或突破字体下限。
