# 独立试题验收、反馈迭代与排版

## 独立 agent 要实际做题

先基于已知需求交付可用 v1 初稿，完成基本内容与版面检查并标出待验收项；不让完整验收循环或漫长的偏好收集阻塞初稿。之后按用户反馈逐步修订。新建小抄或大幅修改准备标为最终版时，在可用的 agent 工具中安排至少一个独立解题 agent。主制作 agent 负责整合；可额外安排一个 agent 检查来源/答案或最终视觉布局。读一句“看起来不错”不能算试题验收。

1. **准备候选版。**固定版本或文件哈希、当前课程约束、所覆盖题型和待测题。按题型选代表题与改变关键条件的必要变式，包含情境问法、易混概念和不同输出形式。用户要求全题验收时才扩大为全题；报告实际范围。
2. **独立解题。**给解题 agent 原题、必要题图和实际候选小抄，包括最终渲染页；不给参考答案、作者的定位提示或预期结论。可以访问小抄本身的索引，不能访问作者另附的答案路线。要求交出真实答案或失败位置。
3. **分开核验。**收到独立作答后，主制作 agent 或另一个审查 agent 才对照官方答案/评分标准和一手课程材料。没有官方答案则独立推导并标注为推导；有争议就保留未决状态。
4. **按证据修复。**将问题分类为入口、条件判断、步骤/输出、事实/计算、版面、范围或来源错误。每条反馈要有具体题目、入口和失败证据，不因审查者喜好反复改样式。
5. **复测。**修改并重新导出、渲染；让独立 agent 在新版本重做失败题，加一个相关变式及少量未改动区域的回归题。编号、颜色或栏位变化也要检查定位。保留旧反馈与修复对应关系。

解题 agent 需返回：

| 题源/题号 | 候选版本 | 从哪些题面词出发 | 找到的实际入口 | 所用条件与步骤 | 完整作答/失败位置 | 小抄外补了什么知识 | 问题证据 |
|---|---|---|---|---|---|---|---|

模型可能凭已有知识答对，所以必须单独记录“小抄支持了什么”和“模型自己补了什么”。答案正确但关键判断来自小抄外知识，不能记为小抄完全支持。没有学生实测时，不编造查找时间或独立掌握证据。

可直接给独立 agent 的任务骨架：

> 用附带候选小抄尝试这些原题。请先独立作答，不看参考答案。每题说明从题面哪个词找到哪个实际条目，列出使用条件、必要中间过程和最终答案。不会定位或缺步骤时直接记录；若用自己的知识补全，请明确列出，不能用补全后的正确答案掩盖小抄缺口。不要修改候选版。

## 反馈表与停止条件

| 轮次 | 问题与证据 | 影响条目 | 修复内容 | 新版本 | 失败题复测 | 变式/回归 | 仍未验证 |
|---|---|---|---|---|---|---|---|

每次最终验收默认执行初次独立验收，发现问题后最多两轮修复与复测；预算或用户指定轮数优先。这是当次内部验收的上限，不限制以后按用户新反馈继续修改。若没有问题，无需制造修改循环。若达到上限仍有严重问题，交付明确标记的待修草稿及剩余问题，不声称最终通过，也不无限重排。

最终接受条件：已确认的考试格式满足；所测题没有未解决的关键错误；修改后完成受影响项复测；所有来源/范围不确定性和未覆盖题型已明确列出；下述实际可执行的版面检查通过。某项工具不可用就标该项未验证，不能以 agent 自述代替结果。

## 排版与字体

- **最小有效印刷字号为 5pt。**这是项目的下限，不是默认正文字号；若考试规定或使用者要求更大，则采用更大的下限。优先使用更易读的字号。
- 检查正文、代码、脚注、图标签、表格、公式上下标等全部承载内容的文字。导出后的变换、缩放也计入：例如 5pt 文字以 90% 打印只有 4.5pt，不合格。转为路径或图片的文字不能靠 PDF 字体清单证明字号，需追踪生成尺寸或另行测量；无法确认则报告未核验。
- 以实际尺寸排版，记录预计打印比例；检查实际可打印边距，不依赖自动“缩小以适合”。不要为了塞满版面静默降到 5pt 以下。必要时去重、缩写已解释的重复项、换栏布局或将长示范移到复习伴随材料。
- 大标题明显大于正文，用稳定编号、模块色带/底色和留白区分；底色不能遮住文字或占用过多空间。子标题让题目关键词独立可扫读，不能只藏在正文中。
- 推荐可调整的语义配色：模块大标题采用深色文字与浅色底带；中文判断/解释使用蓝色标记；英文答案模板使用淡黄底；重要条件/易错点用少量红色或强调标记。每类都有文字标签，不只靠色相。
- “重点”必须说明依据，例如老师明确强调、当前范围核心、学生常错或历史出现；颜色深浅不能暗示无证据的出题概率。遵守考试颜色限制，黑白要求下改用层级、边框、字重和浅灰底。

## 最终文件验收

1. 从最终文件读取页数、页面尺寸、字体与文字位置；确认单/双面限制及有效字号下限。检查导出字体替换、缺字和源文档一致性。
2. 渲染**最终版本的每一页**，检查裁切、跨栏碰撞、行间拥挤、代码括号/缩进、公式与图标签。测过旧版不能代替当前版。
3. 查看实际尺寸的视觉效果及灰度预览，核查标题/正文层级、颜色/底色对比和关键词可见性；不能只看放大后的局部截图。
4. 若有实际打印条件，由使用者按目标比例试印阅读。否则明确“数字版检查通过，实际打印未验证”。agent 做题成功不替代版面检查，渲染检查也不替代物理打印。
5. 保存简短验收记录：版本/哈希、纸张/面数、最小有效字号及测量方法、打印比例、视觉问题、所测试题、agent 反馈轮次、未决项。让读者能分辨实测值、元数据和建议值。
