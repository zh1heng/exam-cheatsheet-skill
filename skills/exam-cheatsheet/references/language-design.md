# 按用途分配语言

多语言小抄的价值是减少识题、判断和作答之间的转换成本。不能把“每段都翻译两遍”当作完成双语设计。

先从已有上下文确定：**题目用什么语言、学生用什么语言思考最快、考试要求什么语言作答、允许小抄使用什么语言**。学生的语言能力和考试规则决定分工，不按国籍推测。只有影响设计的值未知时才询问。

## 每种语言承担什么任务

| 使用环节 | 优先语言 | 作用与检查方法 |
|---|---|---|
| 看见题目、找到小抄 | 题目原语言关键词＋简短的熟悉语言提示 | 保留可识别的原词、问法和必要同义词，避免必须先翻译成理论名称才找得到 |
| 理解、选方法、排除相似方法 | 学生理解最快的语言 | 写具体条件、判断依据、步骤和因果；“找问题、解释原因”这样的任务提醒不够 |
| 记住并辨认课程术语 | 课程原术语＋首次必要释义 | 区分易混词、缩写和课程特定定义，避免译名覆盖考试实际用词 |
| 写出卷面答案 | 考试规定的作答语言 | 给简洁、语法可用、条件正确的句型或骨架；说明空格填什么以及哪些步骤必须展开 |
| 程序、公式和图标签 | 题设规定的代码/数学表示；解释另用熟悉语言 | 标识符、API、大小写、符号、方向和单位不随意翻译或替换；图标签按题面要求 |

对“中文理解、英文考试”的学生，通常是：**英文找入口，中文做判断，英文写答案**。如果考试或学生语言偏好不同，则调整角色；不强制中文，也不因为试卷是英文就默认全英文小抄更好。

## 原创条目示例

**G1 connect all / minimum total cost｜全部连通、总成本最低**

- **中文判断：**题设为连通、无向、带权图，目标是整张连接网络的总边权最低，查 MST；若问从指定起点到各点的最短距离，查 shortest paths。看清 `all`、`total` 与 `from a source` 的差别。
- **中文操作：**Prim 从任一顶点开始；每次取连接已选与未选顶点的最小权边，加入新顶点，直到全体加入。如果仍有未选顶点却没有跨边，图不连通，停止并说明不存在覆盖全部顶点的生成树。记录边并求和；题目要求树图或中间状态时也要给出。
- **English answer:** “Use Prim's algorithm to find a minimum spanning tree. The selected edges are ____. The total cost is ____.” 空格填本题边集合与求和结果；这句话不能替代题目要求的树图或步骤。

英文部分负责对应题面和产生答案，中文部分解释怎么判断与怎么操作。无需把同样的完整算法说明再翻成一整段英文。

## 压缩与准确性

- 不重复整段释义；概念只在确有辨义作用时保留短对照，例如 `flaw（缺陷）` 与 `flow（流程）`。
- 简单英文不等于删掉限制条件。保留否定、量词、因果和比较关系，如 `not`、`all`、`at least`、`expected`、`worst-case`、`necessary/sufficient`；不能为了短而改变命题。
- 课程术语优先于泛化译名或通用展开式；看不懂的缩写应有解释，不把学生默认当成术语专家。
- 中文主要用来承载判断依据，英文模板主要用来承载考试表达；不能只写中文小标题、让所有关键推理仍藏在困难英文中。
- 翻译不是理解验收：能抄模板也不代表知道什么时候用。必须用相似问法、条件变化或情境题检查是否能选对条目。

## 多语言验收

在独立 agent 试题记录中增加必要检查：原题词能否对应实际入口；解释语言是否足以完成判断；答案能否使用规定语言完整表达；模板是否遗漏条件；是否出现错误翻译或不必要重复。让 agent 标出自己补充的翻译、概念或推理；这些补充可能揭示小抄仍缺少桥接。agent 的语言能力不能替代学生的实际查用体验。
